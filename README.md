# PulseCRM — Vue 3 + PrimeVue CRM Lead Management Dashboard (JavaScript Edition)

A modern, responsive SaaS **CRM Lead Management Dashboard** with **Role-Based Authentication (`Admin`, `Sales Manager`, and `Sales Worker`)** built in **pure JavaScript (ES Modules)** with **Vue 3 (`<script setup>`)**, **Vite**, **PrimeVue 4 (`@primeuix/themes/aura`)**, **PrimeIcons**, **Tailwind CSS v4**, **Pinia**, **Vue Router**, and **Chart.js (`vue-chartjs`)**.

---

## Quick Start (Run on `localhost`)

```bash
# 1. Install dependencies
npm install

# 2. Start local dev server
npm run dev
```

Open **`http://localhost:5173`** in your browser. Sign in with any credential below or click **Admin**, **Manager**, or **Worker** on `/login` for instant 1-click access.
